# Changelog

All notable project changes are recorded here.

## [1.0.0] - 2026-11-24

### Added

- Greenfield Python/FastAPI engineering foundation.
- Liveness and versioned API health endpoints.
- Safe environment settings, structured application logs, locked dependencies,
  local tests, and a GitHub Actions workflow.

### Scope

- No database connection, ORM, worker, model provider, frontend, Skill runtime,
  workflow engine, or platform account integration is included in Phase 1.
